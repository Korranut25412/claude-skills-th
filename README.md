# Thai study skills for Claude Code

Four [Claude Code](https://claude.com/claude-code) skills written in Thai for university students. I built and refined them over a semester of real exams (databases, statistics, physics, linear algebra); each rule in them comes from something that went wrong once.

ชุดสกิลภาษาไทยสำหรับนักศึกษาที่ใช้ Claude Code ช่วยเรียน ใช้จริงมาทั้งเทอม ทุกกฎในสกิลมาจากความผิดพลาดที่เคยเกิดจริง

| Skill | พิมพ์ว่า | ทำอะไร |
|---|---|---|
| **drill** | "ติว", "ฝึกโจทย์", "ทดสอบฉัน" | ออกโจทย์ทีละข้อจากไฟล์ในโฟลเดอร์วิชา จับเวลา ไม่เฉลยก่อนตอบ บันทึกข้อผิดพร้อมสาเหตุราก แล้วเอามาถามซ้ำตามรอบ 1 → 3 → 7 วัน (spaced repetition) |
| **cheatsheet** | "ทำชีท", "ชีทสอบ" | ทำชีทเข้าห้องสอบแบบ "เห็นคำนี้ในโจทย์ → ทำแบบนี้" + ตัวอย่างเต็มจากเฉลย + บอกส่วนที่คงเดิม/ต้องเปลี่ยน รันโค้ดและคำนวณตัวเลขทุกชิ้นก่อนลงชีท แล้วตรวจ PDF ว่าฟอนต์ไม่เล็กเกิน |
| **ask-first** | "ถามก่อน" หรือคำขอที่กว้างเกินไป | ถามทีละ 1–3 ข้อแบบมีตัวเลือก จนรู้ว่าต้องการอะไรจริง แล้วค่อยลงมือ ลดรอบ "ไม่ใช่แบบนี้ ขอใหม่" |
| **handoff** | "ปิดแชท", "handoff" | สรุปสถานะงานลง `_สถานะล่าสุด.md` ในโฟลเดอร์ แชทใหม่อ่านต่อได้ทันที ไม่ต้องเล่าใหม่ และไม่เปลืองลิมิตกับแชทยาว |

## ติดตั้ง

ใน Claude Code:

```
/plugin marketplace add Korranut25412/claude-skills-th
/plugin install thai-study-skills@claude-skills-th
```

หรือคัดลอกเฉพาะสกิลที่ต้องการ: เอาโฟลเดอร์ใน `plugins/thai-study-skills/skills/` ไปวางที่ `~/.claude/skills/`

## แนะนำการใช้

1. เก็บไฟล์แต่ละวิชาไว้คนละโฟลเดอร์ (สไลด์ ใบงาน เฉลย ข้อสอบเก่า) แล้วเปิด Claude Code ในโฟลเดอร์นั้น
2. สองสัปดาห์ก่อนสอบ: `ทำชีท` → ได้ชีท PDF
3. ทุกวันก่อนสอบ: `ติว` → 5 ข้อ ~15 นาที ข้อที่ผิดจะกลับมาเองตามรอบ
4. แชทยาวเกินไป: `ปิดแชท` แล้วเปิดแชทใหม่ในโฟลเดอร์เดิม

`drill` ไม่ให้คำตอบก่อนเราตอบเอง เพราะฝึกดึงความรู้ออกมาเองได้ผลกว่าอ่านเฉลย
