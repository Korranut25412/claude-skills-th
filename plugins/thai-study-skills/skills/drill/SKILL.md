# Drill — ติวจับเวลา + ทวนข้อที่เคยผิด

นักเรียนส่วนใหญ่ไม่ได้ขาดความเข้าใจ แต่ดึงความรู้ออกมาใช้ใต้เวลาจำกัดไม่ทัน skill นี้จึงบังคับให้ตอบเองก่อนเสมอ แล้วจำข้อที่พลาดไว้ถามซ้ำตามรอบ

## 1. หาวิชาและไฟล์
- วิชา = โฟลเดอร์ที่เปิดอยู่ หรือชื่อวิชาที่ผู้ใช้พิมพ์ ถ้าไม่รู้ ให้ถามด้วย AskUserQuestion ข้อเดียว
- ออกโจทย์จากไฟล์ในโฟลเดอร์วิชาเท่านั้น (สไลด์ ใบงาน ข้อสอบเก่า) ห้ามออกนอกขอบเขตที่ไฟล์ระบุ
- ถ้าโฟลเดอร์ไม่มีไฟล์เนื้อหาเลย ให้ถามผู้ใช้ว่าจะใช้เนื้อหาจากไหน อย่าแต่งขอบเขตเอง

## 2. เปิดสมุดข้อผิด
- ไฟล์ `<โฟลเดอร์วิชา>/_ฝึก/ข้อผิด.md` (ถ้าไม่มี ให้สร้างพร้อมหัวตารางในข้อ 4)
- ข้อที่ `ทวนวันที่` ≤ วันนี้ และยังไม่ `ผ่าน` ให้เอามาถามก่อน โดยถามโจทย์ใหม่ที่วัดจุดเดียวกัน ไม่ใช่ข้อเดิมเป๊ะ

## 3. รอบฝึก (ค่าเริ่มต้น 5 ข้อ)
ทำทีละข้อ:
1. รันคำสั่ง `date +%s` เก็บเวลาเริ่ม แล้วส่งโจทย์ 1 ข้อพร้อมเวลาแนะนำ (เช่น "⏱ 3 นาที") แล้วหยุดรอ
2. ผู้ใช้ตอบ → รัน `date +%s` อีกครั้ง คำนวณเวลาที่ใช้
3. ห้ามเฉลยหรือใบ้ ห้ามให้โค้ดหรือเทมเพลตตัวอย่างก่อนผู้ใช้ตอบ ถ้าผู้ใช้ขอคำใบ้ ให้ใบ้ทีละน้อยแล้วบันทึกว่าใช้คำใบ้
4. ตรวจ: ถูก / ถูกบางส่วน / ผิด + เวลาที่ใช้เทียบเวลาแนะนำ
5. ถ้าผิดหรือช้าเกิน 1.5 เท่า ให้ระบุสาเหตุรากหนึ่งอย่าง: `คอนเซปต์ผิด` / `จำสูตร-syntax ผิด` / `คำนวณ-ตรรกะพลาด` / `อ่านโจทย์ไม่ครบ` / `ช้าเกิน`
6. เฉลยสั้นๆ เฉพาะจุดที่พลาด ไม่บรรยายพื้นฐานซ้ำ

## 4. บันทึกอัตโนมัติ (ทำทุกข้อ ไม่ต้องถามผู้ใช้)
ตารางใน `_ฝึก/ข้อผิด.md`:

| วันที่ | หัวข้อ | สาเหตุราก | สิ่งที่ต้องจำ (1 บรรทัด) | ทวนวันที่ | รอบ | สถานะ |
|---|---|---|---|---|---|---|

- ผิดครั้งแรก: ทวนวันที่ = พรุ่งนี้, รอบ = 1
- ทวนแล้วถูก: เลื่อน +3 วัน (รอบ 2) → +7 วัน (รอบ 3) → ถูกรอบ 3 = `ผ่าน`
- ทวนแล้วผิดอีก: กลับไปรอบ 1 ทวนพรุ่งนี้
- ถ้าวันทวนเลยวันสอบของวิชา ให้ใช้วันก่อนสอบ 1 วันแทน

## 5. จบรอบ
สรุป 3 บรรทัด: ได้กี่ข้อจากกี่ข้อ / สาเหตุรากที่เจอบ่อยสุด / ข้อที่ค้างทวนพรุ่งนี้กี่ข้อ ไม่ให้กำลังใจ ไม่สรุปยาว
