# Handoff — สรุปแล้วเปิดแชทใหม่

แชทยาวทำให้ลิมิตหมดเร็วและ Claude ลืมรายละเอียดเก่า skill นี้ทำให้การเปิดแชทใหม่ไม่เสียอะไร

## ขั้นตอน
1. หาโฟลเดอร์งานหลักของแชทนี้ (ปกติคือโฟลเดอร์ที่เปิดอยู่ ถ้าคุยหลายเรื่อง ให้เขียนแยกไฟล์ลงโฟลเดอร์ของแต่ละเรื่อง)
2. เขียนทับ `<โฟลเดอร์งาน>/_สถานะล่าสุด.md` ไม่เกิน 40 บรรทัด ตามแบบนี้:

```
# สถานะล่าสุด — <ชื่องาน>
อัปเดต: <วันที่ เวลา>

## เป้าหมาย
<1-2 บรรทัด>

## ทำเสร็จแล้ว
- ...

## ค้างอยู่ / ขั้นต่อไป (เรียงตามลำดับ)
1. ...

## ไฟล์สำคัญ
- `path` — ใช้ทำอะไร

## ข้อตกลง/ตัวเลขที่ยืนยันแล้ว
- ... (ระบุแหล่ง: ไฟล์ไหน / ภาพหน้าจอวันไหน)

## ข้อควรระวัง
- ...
```

3. ถ้ามีข้อเท็จจริงถาวรใหม่ (คะแนนจริง วันสอบ กติกาใหม่ที่ผู้ใช้สั่ง) ให้บันทึกลง memory หรือ CLAUDE.md ด้วย
4. เพิ่มหัวข้อ `## สกิลที่แชทถัดไปควรเรียก` ถ้ามี · ห้ามคัดลอกเนื้อหาที่อยู่ในไฟล์อื่นแล้ว ให้ใส่ path แทน · **ลบความลับทุกชนิด (รหัสผ่าน token connection string) ก่อนเขียน**
5. บอกผู้ใช้ 1 บรรทัด: "บันทึกแล้ว เปิดแชทใหม่ในโฟลเดอร์นี้ได้เลย แชทใหม่จะอ่านไฟล์นี้เอง"

## ให้แชทใหม่อ่านไฟล์นี้เอง
เพิ่มบรรทัดนี้ใน `CLAUDE.md` ของโฟลเดอร์ (หรือ `~/.claude/CLAUDE.md`) ครั้งเดียว:

```
ถ้าโฟลเดอร์งานมี _สถานะล่าสุด.md ให้อ่านก่อนเริ่มงาน ไม่ต้องให้ผู้ใช้เล่าซ้ำ
```
