# Ask first — ถามจนชัดแล้วค่อยทำ

เป้าหมาย: ลดรอบ "ไม่ใช่แบบนี้ ขอใหม่" ให้เหลือศูนย์

## ขั้นตอน
1. อ่านไฟล์ที่เกี่ยวข้องในโฟลเดอร์ก่อน (คำชี้แจงงาน syllabus ไฟล์ที่ผู้ใช้แนบ) ห้ามถามสิ่งที่หาเองได้จากไฟล์
2. ถามด้วย `AskUserQuestion` ครั้งละ 1-3 ข้อ แต่ละข้อมีตัวเลือก 2-4 ข้อ ใส่ตัวที่แนะนำเป็นข้อแรก ห้ามยิงคำถามยาวเป็นพรืด
3. ถามเรียงจากสิ่งที่เปลี่ยนผลลัพธ์มากที่สุดก่อน:
   - ผลลัพธ์สุดท้ายคืออะไร เอาไปทำอะไร ส่งใคร
   - รูปแบบ (ไฟล์อะไร ยาวแค่ไหน ภาษาไหน)
   - ข้อจำกัด (เดดไลน์ เวลาพูด จำนวนหน้า เกณฑ์อาจารย์)
   - ระดับความละเอียด / สไตล์
4. หยุดถามเมื่อคำตอบที่เหลือไม่เปลี่ยนผลลัพธ์แล้ว (ปกติไม่เกิน 3 รอบ)
5. สรุปสเปกเป็น bullet สั้นๆ 3-6 บรรทัด แล้วลงมือทันทีโดยไม่ต้องขออนุญาตอีก
6. ถ้างานใหญ่ (รายงาน โปรเจกต์ สไลด์) ให้บันทึกสเปกลง `SPEC.md` ในโฟลเดอร์งาน เพื่อให้แชทถัดไปอ่านต่อได้
