# ทำชีทสรุปสอบ

สรุปจากการทำชีทสอบจริงหลายวิชา (ฐานข้อมูล สถิติ ฟิสิกส์) ทั้งรูปแบบที่ใช้ได้ผลในห้องสอบ และความผิดพลาดที่เคยเกิดแล้วห้ามเกิดซ้ำ

## 0 · ถามครั้งเดียวก่อนลงมือ (AskUserQuestion 1 รอบ) เฉพาะที่ไฟล์ไม่บอก
- กติกาชีท: กี่แผ่น กี่หน้า หน้า-หลังได้ไหม ขนาดตัวอักษรต่ำสุดที่ยังอ่านไหว สีพื้น
- ขอบเขต: เรื่องไหนออกบ้าง สะสมก่อนกลางภาคไหม (เคยเสียที่เพราะใส่เรื่องที่ไม่ออกสอบ)
- รูปแบบข้อสอบ: เขียน / ปรนัย / คำนวณ / ลงมือในเครื่อง · ตารางสถิติแจกหรือต้องพก · เครื่องคิดเลขได้ไหม
- **ขอข้อสอบจริงรอบก่อนของวิชานั้น** ถ้าไม่มี ให้ถามว่าข้อสอบรอบก่อนถามแบบไหน: ลอกตัวอย่างสไลด์/การบ้าน หรือแต่งโจทย์ใหม่ (สำคัญมาก ดูข้อ 5)
- หลายหน้า: เอาสารบัญไหม

## 1 · แหล่งเนื้อหา เรียงตามความสำคัญ
1. **สไลด์อาจารย์** 2. **การบ้าน/แบบฝึกที่อาจารย์เฉลย** 3. ไฟล์ข้อมูล/แลปของอาจารย์ 4. ข้อสอบเก่า 5. ชีทของเพื่อน (ใช้เช็กว่าขาดอะไร) 6. ความรู้ทั่วไป
- **ต้องครอบคลุมทุกข้อในเฉลยและทุกตัวอย่างในสไลด์ก่อน** ห้ามพลาดสักข้อ
- ของที่เติมเองได้เฉพาะ "ใกล้เคียงเฉลย" (ข้อเดิมเปลี่ยนคำถามนิดเดียว) **ห้ามคิดเนื้อหาใหม่เอง**
- ใช้**คำโจทย์ตามต้นฉบับ** เพราะตอนสอบผู้ใช้จับคู่จากคำ
- สไลด์ที่เป็นรูปล้วน ดึงข้อความไม่ได้ → render เป็น PNG แล้วอ่านภาพ ห้ามข้าม
- จุดที่สไลด์กับเฉลยขัดกัน → ลองจริงว่าอันไหนถูก แล้วเขียนลงชีทว่าใช้อันไหนเพราะอะไร

## 2 · รูปแบบเนื้อหา
- **เห็นคำนี้ในโจทย์ → ทำแบบนี้** ภาษาคน ครอบคลุมทุกกรณีที่เฉลย/สไลด์มี
- **โจทย์ในเฉลยทีละข้อ → วิธี/สิ่งที่ต้องเติม** (ตาราง ใช้คำโจทย์ตามเฉลย)
- **ตัวอย่างเต็มทั้งก้อนต่อหัวข้อ** (เอามาจากเฉลยจริง ลอกได้ทั้งก้อน) แล้วใต้ก้อนเขียน 3 บรรทัด:
  - **คงเดิม** (ป้ายเขียว) ส่วนที่ลอกตรงทุกข้อ
  - **เปลี่ยน** (ป้ายส้ม) ① ② ③ จุดที่ต้องแก้ตามโจทย์
  - **ถ้าโจทย์เห็น "…"** → แก้บรรทัดไหนเป็นอะไร
- ค่าที่ต้องเปลี่ยนในตัวอย่าง = **สีส้มเส้นประ** ที่เหลือลอกตรง
- วิชาคำนวณ (สถิติ ฟิสิกส์ คณิต): ชนิดโจทย์ → สูตร → ขั้นตอน → **ตัวอย่างแทนตัวเลขครบจนได้คำตอบ + หน่วย** → ตัวเลขไหนเปลี่ยนตามโจทย์ → ต้องเปิดตารางอะไร (z/t/χ²/F) ที่ค่าไหน
- **นิยามสั้นของทุกคำศัพท์**ที่อาจารย์ใช้ (ชีทที่มีแต่วิธีไม่มีนิยาม ทำให้อ่านโค้ดตัวเองไม่ออกตอนซ้อม)
- บล็อก **"คิดทีละขั้น"** สำหรับเรื่องที่ผู้ใช้ไม่เข้าใจที่สุด
- ตาราง **กับดัก / error ที่พลาดบ่อย** (รวมกรณีที่ผลผิดแต่ไม่ error)
- เขียนให้อ่านได้ทางเดียว: "ใช้ WHERE ไม่ได้ (error 1111)" ไม่ใช่ "ใช้ WHERE ได้ 1111"

**ห้ามใส่:** ยกสไลด์ทั้งดุ้น · ตารางข้อมูลตัวอย่างของแบบฝึก · "ผลลัพธ์ที่ควรได้" · ขั้นตอนใช้เครื่องมือที่ไม่ออกสอบ · บล็อกอธิบายวิธีใช้ชีท · เรื่องนอกขอบเขต

**ห้ามเหลือที่ว่าง:** เหลือที่ → เติมจากเฉลย/สไลด์ก่อน → แล้วค่อยแบบใกล้เคียง → ถ้ายังเหลือให้ขยายฟอนต์

## 3 · จัดหน้า
- **เรียงตามเรื่อง/สัปดาห์ ไหลซ้าย→ขวา หน้า→หลัง** มีแถบหัวเรื่องคั่นแต่ละเรื่อง (ชีทที่แยกหน้า/หลังตามประเภททำให้ต้องพลิกหา) · เลขบล็อกต้องเรียง
- ห้ามเล็กกว่าขนาดที่ตกลง ต่ำกว่า ~5pt เริ่มอ่านยาก → หลายหน้าให้ใช้ 7-9pt แล้วเพิ่มหน้าแทนการย่อ
- Pipeline ที่ใช้ได้จริง: HTML + CSS (หลายคอลัมน์) → Chrome headless `--print-to-pdf` → ตรวจ PDF ด้วย pymupdf 4 อย่าง: จำนวนหน้า · ตัวอักษรหาย (เทียบข้อความต้นทางกับ PDF) · **ขนาดฟอนต์จริงใน PDF** (ค่าที่ตั้งใน CSS อาจไม่ตรงกับที่พิมพ์ออกมา) · หมึกชิดขอบ → แล้ว render PNG ดูด้วยตาทุกหน้า
- สูตรคณิต: KaTeX (ใส่ `--virtual-time-budget` ให้ render ทัน) หรือ Unicode ธรรมดา แล้วตรวจใน PDF ว่าขึ้นจริง
- `<pre>` ที่มีคอมเมนต์ยาวจะตัดบรรทัดเละ → เขียนคำอธิบายไว้นอก pre
- ไฟล์รุ่นก่อนย้ายเข้า `ชีทสอบ/ฉบับเก่า/` ไม่ลบ

## 4 · ตรวจความถูกต้องก่อนส่ง
- **ทุกโค้ดต้องรันจริง ทุกตัวเลขต้องคำนวณจริง** (Python: numpy / scipy.stats / sympy) ก่อนลงชีท แม้ตัวอย่างจะมาจากสไลด์ (สไลด์ก็ผิดได้)
- **audit ความครบด้วย subagent**: ให้อ่านแหล่งทุกไฟล์ + ชีท แล้วคืน 4 ส่วน: A ข้อที่ขาด (อ้างจากแหล่งตรงตัว) · B ข้อที่ครบ · C ของในชีทที่ไม่มีในแหล่ง · D จุดที่แหล่งขัดกับชีท → แก้ A, ตัด C ที่ไม่มีในแหล่งเลย, จัดการ D
- ข้อสอบจำลอง (ถ้าเหลือ ≥ 3 วัน): agent ตัวหนึ่งออกข้อสอบจากไฟล์อาจารย์โดยไม่เห็นชีท อีกตัวทำโดยเปิดแค่ชีทแล้วจดทุกจุดที่ชีทไม่มี ทำ**ก่อน**จัดหน้าสวย

## 5 · บทเรียนใหญ่: ชีทแบบลอกตรงใช้ไม่ได้ถ้าอาจารย์แต่งโจทย์ใหม่
- เคยเกิด: ชีทภาคทฤษฎีทำจากตัวอย่างในสไลด์ แต่อาจารย์แต่งโจทย์ใหม่ทั้งหมด ไม่มีข้อไหนตรงตัวอย่าง ชีทช่วยไม่ได้เลย
- **ชีทแบบลอกตรงใช้ได้เฉพาะส่วนที่ยืนยันแล้วว่าข้อสอบลอกการบ้าน** ส่วนที่ไม่รู้แนว ต้องทำเป็น "วิธีคิดที่ใช้กับโจทย์ไหนก็ได้" (แยกชนิดโจทย์ → สูตร → โครงคำตอบ)
- **ข้อสอบจำลองต้องเป็นโจทย์ใหม่ที่ไม่ใช่ตัวอย่างในสไลด์** และผู้ใช้ต้องลองทำเองอย่างน้อย 1 รอบ (agent ทำได้ไม่ได้แปลว่าผู้ใช้ทำได้)
- **ห้ามปล่อยให้ผู้ใช้เชื่อว่า "ไม่มีพื้นก็ตอบได้"** บอกตั้งแต่ต้นว่าชีทช่วยแค่โจทย์ที่ตรงแนว
- ทำชีทให้เสร็จ **ก่อนสอบ ≥ 2 วัน** เพื่อเหลือเวลาซ้อม (ใช้คู่กับ skill `drill`)

## 6 · ความผิดพลาดที่เคยเกิด อย่าให้เกิดซ้ำ
| ผิดอะไร | กันยังไง |
|---|---|
| คิดเนื้อหาเพิ่มเองเกินเฉลย ผู้ใช้ต้องสั่งตัด | ครบเฉลย+สไลด์ก่อน ของเติมต้องใกล้เคียงและเช็กกับแหล่ง |
| ใส่เรื่องที่ไม่ออกสอบ | ถามขอบเขตตั้งแต่ข้อ 0 |
| แยกหน้าหน้า/หลังตามประเภท ต้องพลิกหา | ไหลต่อตามเรื่อง มีหัวเรื่องคั่น |
| ไม่มีนิยามคำศัพท์ | นิยามสั้นทุกคำ |
| ตัวอย่างใช้ชื่อเฉพาะโดยไม่บอกว่าต้องแก้อะไร | ส้มเส้นประ + คงเดิม/เปลี่ยน/ถ้าโจทย์ |
| ใส่ผลลัพธ์ที่ควรได้ + ข้อมูลตัวอย่าง เปลืองที่ | ไม่ใส่ |
| บีบฟอนต์จนเหลือ 4pt | ตกลงขนาดต่ำสุดก่อน |
| ลอกตัวอย่างสไลด์ที่ผิดโดยไม่รัน | รันทุกชิ้นก่อนลงชีท |
| ไม่เห็นว่าไฟล์แลปคนละชุดกับใบงาน | เทียบสไลด์/ใบงาน/เฉลย/ไฟล์ข้อมูลตั้งแต่ต้น |
| แก้ทีละนิดหลายสิบรอบ เปลือง quota | ถามเงื่อนไขครบรอบเดียว แล้วทำเป็นก้อนใหญ่ · งานอ่านไฟล์ยาว/audit ส่ง subagent |
| ข้ามสไลด์ที่เป็นรูป | render แล้วอ่านภาพ |

## 7 · ลำดับทำงาน
1. ข้อ 0 ถามรอบเดียว
2. รายชื่อไฟล์อาจารย์ทั้งหมดในโฟลเดอร์วิชา ดึงข้อความ + render หน้าที่เป็นรูป
3. ทำ checklist ทุกข้อในเฉลย + ทุกตัวอย่างในสไลด์ (ส่ง subagent ได้)
4. เขียนเนื้อหาให้ครบ checklist + รัน/คำนวณตรวจทุกชิ้น
5. audit ความครบด้วย subagent แล้วแก้
6. ข้อสอบจำลอง ถ้ามีเวลา
7. จัดหน้า หาฟอนต์ใหญ่สุดที่ลง render ตรวจ 4 อย่าง + ดูภาพ
8. ส่งไฟล์ บอก: กี่หน้า ฟอนต์เท่าไหร่ ครบตามแหล่งไหม อะไรยังไม่ได้ตรวจ
